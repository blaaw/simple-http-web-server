Acerca de

Este proyecto es un servidor web simple escrito en Java. Nació como un servidor HTTP mínimo para aprender los fundamentos de la programación de redes y los objetos lectores, y ahora también sirve páginas estáticas según la URL que pide el cliente.

  • Lee y parsea la petición HTTP del cliente.
  • Sirve archivos HTML desde la carpeta public/.
  • Responde con una página de error 404 cuando el archivo no existe.
